## Editorial principles

This project follows the following distinction:

- Fact
- Interpretation
- Hypothesis
- Roadmap
- Scenario
- Editorial opinion

Roadmaps are not scientific certainties. Future scenarios are not predictions. Hypotheses are not facts.
