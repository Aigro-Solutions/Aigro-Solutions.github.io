# 7. Work, tasks, and the human component

A profession is not a single indivisible unit. It is a bundle of tasks. This is the central organizing principle of the ENS · ARS framework.

Each task contains:

- a component that is potentially automatable;
- a component that requires human judgment, contextual understanding, ethics, or responsibility.

The question becomes not whether an occupation disappears in full, but which parts of the work can be automated and which remain human.
